# Warlock

A turn-based ASCII roguelike in the spirit of ADOM, rendered on the GPU with colored dynamic light,
perception-dependent vision, animated glyphs, and glyph-based effects.

- What we are building: [`specification.md`](specification.md)
- How to build, test, and contribute: [`CLAUDE.md`](CLAUDE.md)

```sh
cargo run -p warlock          # play
cargo test --workspace        # test
```
