# Controls

The game is played with the keyboard. These are the default keys for play. You can rebind every
one of them (see [Rebinding keys](controls-rebinding.md)), and the hints on screen always name your own
keys. In the game, `?` shows the list made from your current keys, so trust it over this page.
[The screen](the-screen.md) explains what the window shows: the map, the message line, the status
bar, and the info pages.

> **The ten keys you need first**
>
> | Key | Does |
> |---|---|
> | numpad or arrows | move; move into a [hostile](creatures.md#factions) creature to attack it |
> | numpad `5` or `s` | wait a turn, [searching](searching.md#how-to-search) around you |
> | `,` | [pick up](objects.md#picking-up) what is underfoot |
> | `i` | [equipment](equipment.md): wear and wield |
> | `a` | the [abilities menu](abilities.md#the-abilities-menu): spells, class abilities, skill uses |
> | `t` | [shoot or throw](ranged.md#shooting-and-throwing) |
> | `>` / `<` | down or up [stairs](terrain.md#stairs) |
> | `l` | [look around](controls-prompts.md#look-mode) |
> | `?` | every key, as you have bound it |
> | `Esc` | the [pause menu](the-screen.md#menus): save and quit |

## All the keys

| Command | Keys |
|---|---|
| Move (numpad) | `8` `9` `6` `3` `2` `1` `4` `7` |
| Move (arrows) | Up, Right, Down, Left (four directions) |
| [Run](turns.md#running) (step after step until something stops you) | `Alt` with a movement key (`Option` on a Mac) |
| Attack | move into a [hostile](creatures.md#factions) [creature](creatures.md) |
| [Swap places](npcs.md#getting-past) | move into any other creature |
| [Chat](npcs.md#chatting) with someone next to you | `C` (then a direction, if several are near; see [Something beside you](controls-prompts.md#something-beside-you)) |
| Wait a [turn](time.md#what-takes-time), [searching](searching.md#how-to-search) the cells around you | numpad `5` or `s` |
| Search for a while (up to 10 turns, stops when something turns up) | `Alt` with `s` or numpad `5` (`Option` on a Mac) |
| Open a [door](doors.md) or a [chest](chests.md) | `o` (then a direction, if several are beside you; or walk into the door) |
| Close a door | `c` (then a direction, if several are beside you) |
| [Kick](doors.md#kicking-a-door-open) (a door, to break it in, or a creature) | `k`, then a direction, always |
| Go down [stairs](terrain.md#stairs), or enter a place on the [overworld](overworld.md#locations) | `>` |
| Go up stairs, or [leave an outdoor area](overworld.md#leaving-an-area) when no enemy is about | `<` |
| [Pick up](objects.md#picking-up) | `,` or `;` |
| [Drop](objects.md#dropping) (your [pack](objects.md#your-pack) in its drop mode; `D` there too) | `d` |
| [Pay](shops.md#buying) the [shopkeeper](creatures.md#creature-shopkeeper) | `p` |
| [Equipment](equipment.md) ([wear and wield](equipment.md#what-fits-where)) | `i` |
| Inventory (your pack) | `I` |
| [Character](the-screen.md#character) (your [stats](stats.md) and weight) | `@` |
| [Skills](the-screen.md#skills) | `A` |
| [Weapon skills](weapon-skills.md) | `W` |
| [Quest log](quests.md#the-quest-log) | `q` |
| [Talents](talents.md) (yours, and every other with what it needs) | `G` |
| [Message history](the-screen.md#messages) | `v` |
| [Info page](the-screen.md#info-pages) 1 to 9 (while an info screen is open) | `1` to `9` |
| Next / previous info page (wraps) | `Tab` / `Shift`+`Tab` |
| [Rest](resting.md#how-resting-works) | `b` |
| Consume ([eat](food.md#eating)) | `e` |
| Read a [scroll](scrolls.md) | `r`, choose it, then aim a [spell](magic.md) |
| [Look around](controls-prompts.md#look-mode) | `l` |
| [Shoot or throw](ranged.md#shooting-and-throwing) what is in your [Missile weapon slot](ranged.md#getting-ready) | `t`, then [aim](controls-prompts.md#aiming) |
| Throw something from your pack | `T`, choose it, then aim |
| More aggressive combat [stance](stances.md#stances), more defensive (no time passes) | `+`, `-` |
| [Abilities](abilities.md#the-abilities-menu): everything you can do because of who you are, in one menu | `a` (see [Abilities](abilities.md)) |
| Use the ability you used last again | `X` |
| [Bash](abilities.md#ability-shield-bash) with your shield (an ability: also in the abilities menu) | no key until you bind one, then a direction |
| [Throw your voice](hearing.md#throwing-your-voice) (an ability: also in the abilities menu) | no key until you bind one, then aim |
| [Disarm a trap](traps.md#disarming-traps) (an ability: also in the abilities menu) | no key until you bind one, then a direction |
| [Steal](abilities.md#ability-steal) (an ability: also in the abilities menu) | no key until you bind one, then a direction |
| Next target while aiming (with Shift: the one before) | `Tab` |
| Use a tool: light, hood, or douse a [lantern](lantern.md) ready in the Tool slot; else [dig](digging.md) into a wall with a pick-axe | `u` (to dig, then a direction) |
| Show or hide the controls | `?` |
| Show the next messages at `--more--` / skip the rest | `Space` or `Enter` / `Esc` |
| Yes / no, when a question asks | `y` / `n` |
| [Pause menu](the-screen.md#menus) | `Esc` |

Wherever [ADOM](https://www.adom.de/) has the same command, the default key is ADOM's, so ADOM
players find keys where their fingers expect them. You move with the numpad or the arrows; the
arrows move in four directions only. If you prefer the vi keys (`hjklyubn`), bind them in
Controls. Give Kick, Look around, and Use a tool other keys first, since they use `k`, `l`, and
`u`, as in ADOM.

Some commands ADOM does not have, or has only behind a prefix. They get keys ADOM leaves free:
the message history `v`, rest `b`, the
talents `G`, and repeating an ability `X`. Waiting and searching are
one command, numpad `5` or `s`, and searching for a while is `Alt` with either. You save and quit from the pause menu (`Esc`), or
bind a key for it in Controls.

Symbol keys such as `<`, `>`, and `?` are matched by the character they type, so they work on any
keyboard layout.
